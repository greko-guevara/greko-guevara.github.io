## Software, Programming, and Computational Modeling

My work integrates programming, numerical modeling, and data analysis as tools
to support engineering design, research, and education in agricultural and
water-related systems.

I primarily use **Python** and open-source tools to develop reproducible workflows
for irrigation, hydraulics, hydrology, and soil–water processes.

---

## Programming Languages and Tools

- **Python** (primary language)
  - Numerical computing (NumPy, SciPy)
  - Data analysis (Pandas)
  - Visualization (Matplotlib)
  - Scientific modeling (Scikit-learn)
- **CAD and GIS tools**
  - QGIS for spatial analysis and hydrological applications
  - AutoCAD for engineering design
- **Engineering software**
  - Hydraulic and irrigation system analysis tools
  - Epanet and WaterCAD
- **Excel**
  - Hydraulic and irrigation sheets
  - Excel for data management.  
- **Version control**
  - Git and GitHub for collaborative and reproducible development

## Educational and Reproducible Code

A significant part of my software work is oriented toward **education and capacity
building**, particularly in engineering and agricultural sciences.

This includes:
- Teaching Python for engineers
- Developing clear and well-documented examples
- Creating computational notebooks and scripts for learning purposes
- Promoting reproducible and open educational resources

---

## Philosophy of Computational Work

I believe that programming and modeling should serve as **transparent and
interpretable tools** that bridge theory, engineering practice, and education.
My approach emphasizes clarity, physical understanding, and reproducibility
over black-box solutions.
